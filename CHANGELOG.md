# Changelog

## 1.2.0
- Updated for Valheim 1.0 (Unity 6). Rebuilt against the 1.0.7 game assemblies and BepInExPack_Valheim 5.4.2350.
- Bundled ServerSync rebuilt for 1.0 (the old build crashed on load).
- Added the new `DeepNorth` build category to the config. Despite the name it holds the new 67-degree steep roof, wall and beam pieces, so it defaults to free like the other building tabs.
- Modded category config descriptions now use the label from the piece table.
- Fixed a null reference when a piece could not be resolved while checking requirements.
- Config version requirement raised to 1.2.0.

## 1.1.0
- Last release by the original author (Jammerbam), for Valheim 0.22x.
